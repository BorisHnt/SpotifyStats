MODE D'EMPLOI

Trois clics, zéro serveur.

01. Demande ton export

Dans les paramètres de confidentialité de Spotify, demande l'« Historique d'écoute étendu ». L'export classique est également accepté, avec moins de détails.

02. Importe le ZIP

Dépose directement le fichier ZIP téléchargé. Pas besoin de le décompresser, ni de fournir une clé API.

03. Explore librement

Tous les calculs sont réalisés sur ton appareil. Le contenu original, notamment les adresses IP ou appareils, n'est ni affiché, ni sauvegardé, ni envoyé.
